# Hi there 👋

I build practical, privacy-friendly tools for people learning to code.

## 🚀 Featured project

### [CodeMentor](https://github.com/Roni0master/codementor)

**An offline coding mentor for students.** Paste an error or your code, and it explains what went wrong, shows the fix and teaches the concept behind it, with no internet connection.

- 🐞 Decodes 80+ error types across Python, JavaScript, Java, C/C++, SQL and Git
- 🔍 Static analyzer that finds bugs with line numbers and auto-fixes the safe ones
- 🧠 Concept library with analogies, examples in 5 languages and quizzes
- 🔐 Private by design: everything runs and stays on the user's device
- ✅ Zero dependencies, 219 automated checks, MIT licensed
